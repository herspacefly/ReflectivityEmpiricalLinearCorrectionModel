# 反射率经验校正模型工具改动总结

本工具最初是一个纯前端 HTML 工具，用于读取 Excel/CSV 表格，并基于四个波段（蓝、绿、红、近红外）的 DN 值与实测反射率计算经验线性校正方程。最后版本在保留原有上传、字段匹配、地物筛选、结果展示、散点图和异常点检测能力的基础上，升级为支持多模型拟合、自动模型对比和置信带可视化的遥感反射率校正工具。

## 相比原始版本的主要改动

### 1. 从单一线性模型升级为多模型校正

原始版本只支持线性模型：

```text
y = ax + b
```

最后版本新增了“校正模型类型”下拉框，支持以下模型：

- 线性：`y = ax + b`
- 二次多项式：`y = ax² + bx + c`
- 三次多项式：`y = ax³ + bx² + cx + d`
- 指数：`y = a * e^(bx)`
- 对数：`y = a * ln(x) + b`
- 幂函数：`y = a * x^b`
- 自动对比全部模型

所有模型均使用原生 JavaScript 实现，没有引入新的第三方回归库。

### 2. 新增通用回归计算框架

原始版本中的线性回归逻辑已升级为通用模型拟合框架：

- `fitModel(xData, yData, modelType)`：根据模型类型拟合参数，并返回系数、R²、调整后 R²、RMSE 和有效样本索引。
- `predictModel(modelType, coefficients, x)`：统一用于模型预测。
- `formatEquation(modelType, coefficients, ratioScale)`：根据模型类型生成动态公式字符串。

多项式模型使用正规方程和高斯消元求解；指数、对数、幂函数通过对数变换转为线性回归后再还原到原始尺度计算评价指标。

### 3. 新增调整后 R²

结果表格和指标卡中新增“调整后 R²”，用于降低高阶模型过拟合带来的误导。

计算公式为：

```text
Adjusted R² = 1 - [(1 - R²) * (n - 1) / (n - p - 1)]
```

当样本数不足以计算调整后 R² 时，页面显示 `--`。

### 4. 增强样本有效性校验

最后版本针对不同模型增加了样本量和非法值校验：

- 二次多项式至少需要 4 个有效样本点。
- 三次多项式至少需要 5 个有效样本点。
- 指数模型会过滤 `y <= 0` 的样本。
- 对数模型会过滤 `x <= 0` 的样本。
- 幂函数模型会过滤 `x <= 0` 或 `y <= 0` 的样本。
- 指数、对数、幂函数过滤后至少需要 3 个有效样本点。

### 5. 新增自动对比全部模型

最后版本新增 `自动对比全部模型` 模式。

选择该模式并点击计算后，工具会对每个波段分别计算 6 种模型，并在结果表格中展开展示。每个波段下会列出 6 行模型结果。

最优模型选择规则：

1. 优先选择 RMSE 最小的模型。
2. 如果 RMSE 相同，则选择调整后 R² 最大的模型。

最优模型行会以浅绿色背景高亮，并显示“最优”标签。

### 6. 异常点检测改为模型驱动

原始版本的异常点检测只使用线性模型预测值。

最后版本中，异常点检测统一使用当前选中的模型：

- 单模型模式下，使用该单一模型预测。
- 自动对比模式下，使用每个波段被选中的最优模型预测。

“模型预测/%”“残差/%”和“标准化残差”均基于实际使用的模型重新计算。

### 7. 散点图从拟合直线升级为拟合曲线

原始版本只绘制线性回归直线。

最后版本会根据当前模型生成不少于 50 个 DN 插值点，并绘制对应的拟合曲线。对于二次、三次、指数、对数和幂函数模型，图中显示的是模型曲线而不是直线。

自动对比模式下，每个波段图表默认绘制该波段的最优模型曲线。

### 8. 新增 95% 预测带可视化

最后版本在散点图中新增近似 95% 预测带：

```text
上界 = y_pred + 1.96 × RMSE
下界 = y_pred - 1.96 × RMSE
```

如果下界小于 0，会截断为 0。上下界之间的区域使用半透明蓝色填充，便于观察样本点相对模型预测范围的偏离程度。

### 9. 结果表格和导出 CSV 升级

结果表格新增内容：

- 模型类型
- 调整后 R²
- 自动对比模式下的最优模型高亮

导出 CSV 也从线性专用字段升级为通用模型字段，包含：

- `ModelType`
- `IsBest`
- `Coefficients_percent_scale`
- `Equation_ratio_scale`
- `R2`
- `Adjusted_R2`
- `RMSE_percent`
- `Error`

这样导出的结果可以同时表达线性模型、非线性模型和自动对比结果。

## 当前版本文件

当前工具主文件为：

```text
反射率经验校正模型（可自选模型或自动对比）.html
```

该文件仍然是单文件纯前端应用，可直接在浏览器中打开使用。Excel 解析依赖在线 SheetJS；如果离线环境无法读取 Excel，可将表格另存为 CSV 后上传。
